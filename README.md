A simple and responsive Weather App that allows users to search for real-time weather information and a 5-day forecast for any city. The app displays key weather details such as temperature, humidity, wind speed, pressure, visibility, and weather conditions, with support for switching between Celsius and Fahrenheit.

🚀 Features

🔍 Search weather by city name

🌡️ Toggle temperature units (°C / °F)

☁️ Current weather conditions with icon

💧 Humidity, 🌬️ wind speed, 📊 pressure, 👀 visibility

📅 5-day weather forecast

📱 Responsive and clean UI

🖥️ Tech Stack

HTML – Structure

CSS – Styling & layout

JavaScript – Logic & API handling

Weather API (e.g., OpenWeatherMap) – Real-time weather data


⚙️ How It Works

User enters a city name in the input field.

Clicks Get Weather to fetch weather data.

App calls the weather API and displays:

Current temperature

Weather description and icon

Humidity, wind speed, pressure, visibility

A 5-day forecast is shown below the current weather.

User can switch between Celsius and Fahrenheit using the toggle button.

🛠️ Setup Instructions

Clone the repository:

git clone https://github.com/Ashok9725/Weather-App.git

Navigate to the project folder:

cd weather-app

Open index.html in your browser.

(Optional) Add your API key in the JavaScript file:

const API_KEY = "YOUR_API_KEY_HERE";
